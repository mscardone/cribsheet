# CribSheet typography

Nunito is used throughout the app: logo, headings, body, buttons, forms, charts, calculation displays, and sync codes. Locally hosted variable WOFF2 fonts support weights 400–800 with Latin, extended Latin, Cyrillic, extended Cyrillic, and Vietnamese subsets.

Source: https://fonts.googleapis.com/css2?family=Nunito:wght@400..800&display=swap
Upstream: https://github.com/google/fonts/tree/main/ofl/nunito
Retrieved: 2026-10-13. License: OFL-Nunito.txt.

All font subsets and nunito.css are included in the offline shell; Latin is preloaded. No runtime font-service requests. The obsolete wordmark-only subset was removed.
