# CribSheet wordmark font

Nunito Bold, weight 700. SIL Open Font License; see OFL-Nunito.txt.

Source: https://github.com/google/fonts/tree/main/ofl/nunito
Retrieved: 2026-10-13
Google Fonts request: https://fonts.googleapis.com/css2?family=Nunito:wght@700&text=CribSheet&display=swap

This compact WOFF2 subset contains only the characters in CribSheet. It is used exclusively for the wordmark, hosted locally, preloaded, and cached for offline use. No runtime Google Fonts connection is required.
